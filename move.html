舊代禱卡怎麼搬過來？

「金香壇代禱卡」已經搬到新家「我的代禱卡．小區代禱牆」。你原本的名單，大多只要按一個按鈕就搬好了。

方法 1

點舊的網址或桌面圖示

適合：手機桌面上還有舊的「金香壇代禱卡」圖示，或收藏了舊網址的人。

  1. 照平常一樣，點舊的圖示或舊網址。畫面會自動跳到新網站。
  2. 按紅色大按鈕 同步代禱名單。
  3. LINE 會問你要不要讓這個網站使用 LINE，按 「許可」。（只有第一次會問）
  4. 回到代禱卡，看到 「✓ 代禱名單同步好了」 就完成了。
  5. 名字都在原來的日子裡：主日家人、週一親戚……一個都沒少。

還沒按也沒關係：每次從舊網址進來，都會再出現這個按鈕，直到同步完成為止。

不想用 LINE 登入？可以按下面的「先不要登入，只在這支手機使用」。名字會先放在這支手機上，但畫面會一直提醒你「同步代禱名單」；換手機或清除瀏覽器資料就會不見，建議還是同步到 LINE。

方法 2

直接打開新網站

適合：以前在這支手機的這個瀏覽器用過舊代禱卡，現在直接打開 praywall.pages.dev 的人。

  1. 打開新網站，畫面會短暫顯示「正在檢查這支手機上舊的代禱卡…」，馬上就回來。
  2. 如果找到舊名單，會出現 同步代禱名單，按下去。
  3. LINE 跳出確認畫面，按 「許可」。
  4. 看到「✓ 代禱名單同步好了」就完成了。

為什麼要「同一個瀏覽器」？舊名單存在你當初用的瀏覽器裡（例如 Safari 或 Chrome）。換了瀏覽器、或在 LINE 裡打開，可能讀不到，請改用方法 1（點舊網址）或方法 4（同步碼）。

方法 3

從 LINE 群組的圖卡打開

適合：已經在 LINE 裡用過新網站（登入過）的人。

  1. 在小區或小排的 LINE 群組，點代禱牆圖卡，或點「我的代禱卡」入口。
  2. 如果這支手機的 LINE 裡有舊代禱卡的名單，會自動同步，不用按任何按鈕。
  3. 看到「✓ 代禱名單同步好了」，按 好 收起來。

已經登入過的人，從方法 1、2 進來也一樣：不會再出現按鈕，直接自動同步。

方法 4

換了新手機：用「同步碼」接回

適合：以前在舊代禱卡設過「雲端同步」，現在換了手機或換了瀏覽器的人。同步碼是 20 個英文字母和數字。

  1. 找出你的同步碼：在舊代禱卡最下面點 「☁ 同步設定」。
  2. 按 複製同步碼，或把那 20 碼抄下來。
  3. 打開新網站的「我的代禱卡」，往下找到 名單代碼，按下去。
  4. 在「以前在金香壇代禱卡設過雲端同步碼」下面的格子貼上（或輸入）同步碼，按 接回舊名單。
  5. 看到「已接回舊名單，加入 N 個名字」就完成了。

舊手機不見了，也忘了同步碼？舊網址還保留舊版：打開舊版代禱卡，在任何一支設過同步的手機上就看得到同步碼。輸入時大小寫、有沒有「-」都沒關係。

方法 5

用「名單代碼」（GIA1. 開頭）

適合：同伴把名單傳給你，或你想把舊代禱卡的名單複製過來。新舊網站的名單代碼互通。

  1. 在舊代禱卡按 複製名單代碼（同伴傳來的代碼就直接複製）。
  2. 打開新網站的「我的代禱卡」，按 名單代碼。
  3. 在上面的大格子長按、貼上，按 匯入名單。
  4. 看到「已匯入 N 個名字」就完成了。

舊代禱卡的「含名單的連結」也可以用：直接點那個連結，就會跳到新網站並把名單帶過來。

常見問題

同步會不會把我在新網站加的名字蓋掉？

不會。每一種方法都是「合併」：把舊名單裡新網站還沒有的名字加進來，原有的名字都保留，同一個名字不會出現兩次。

為什麼要用 LINE 登入？

名單跟著你的 LINE 帳號存到雲端，換手機、清除瀏覽器資料都不會不見；也可以用小區、小排的代禱牆。第一次登入時 LINE 會請你按「許可」，之後就不用再按。

我按了同步，可是說「舊代禱卡裡沒有找到名字」？

代表這個瀏覽器裡沒有舊名單。請改用方法 4（同步碼）或方法 5（名單代碼），在你當初用舊代禱卡的那支手機上操作。

同步碼會被別人看到嗎？

不會。新網站和舊網站一樣，只保存由同步碼算出來、無法反推回去的代號，不保存同步碼本身。請不要把同步碼傳給別人。

以前加到手機桌面的圖示還能用嗎？

可以，點了會自動跳到新網站。同步好之後，建議在新網站重新「加入主畫面」，以後就直接打開新家。

還是不會操作怎麼辦？

請把這一頁傳給小排裡熟悉手機的弟兄姊妹，請他陪你按一次；用方法 1 通常只要按兩下。
